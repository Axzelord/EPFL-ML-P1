# EPFL-ML-P1

EPFL Machine Learning Project 1: preprocess the data and train logistic-regression
and MLP models to predict the likelihood of a person developing a CVD based on their personal lifestyle factors.

## Run

Open and run [`run.ipynb`](run.ipynb) with Python, Jupyter, NumPy, and Matplotlib.
The notebook expects `x_train.csv`, `y_train.csv`, and `x_test.csv` in
`src/dataset/`. It writes predictions to `submission_demo.csv`.
